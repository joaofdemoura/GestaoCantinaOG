# Gestão Cantina OG

Projeto de aplicativo Android para auxiliar na gestão da Cantina OG.

## Status

Em desenvolvimento inicial. O projeto Android possui uma estrutura básica em Kotlin; as funcionalidades de gestão serão implementadas nas próximas etapas.

## Tecnologias

- Kotlin
- Android SDK
- Gradle
- Android Studio

## Como executar

Após os arquivos do aplicativo serem adicionados ao repositório:

1. Abra a pasta do projeto no Android Studio.
2. Aguarde a sincronização do Gradle e instale o Android SDK 34, se solicitado.
3. Selecione um emulador ou dispositivo com Android 7.0 (API 24) ou superior.
4. Clique em **Run** para executar o aplicativo.

## Como contribuir

Clone o repositório e crie uma branch para suas alterações:

```bash
git clone https://github.com/joaofdemoura/GestaoCantinaOG.git
cd GestaoCantinaOG
git switch -c minha-alteracao
```

Após editar os arquivos, confira as alterações e envie seu commit:

```bash
git status
git diff
git add README.md
git commit -m "docs: atualiza README"
git push -u origin minha-alteracao
```

O exemplo adiciona apenas o README. Para outras alterações, informe os arquivos desejados no comando `git add`. Depois do envio, abra um Pull Request no GitHub para integrar a branch à `main`.
