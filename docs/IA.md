# Uso de Inteligência Artificial no projeto

No desenvolvimento do **Cantina Digital / GestaoCantinaOG**, utilizamos o **Codex, da OpenAI**, como assistente de programação. Seu uso incluiu explicações técnicas, geração e edição de código, correções e testes, a partir das telas e dos requisitos definidos pelo responsável pelo projeto.

## Principais aplicações

- **App Android:** implementação e ajustes em Java e XML, incluindo navegação, campo turma e CPF do filho no login do responsável.
- **Integração web e app:** desenvolvimento e correção da comunicação com a API PHP e o banco MySQL, incluindo regras de pedidos, saldo e limites.
- **Ambiente e banco:** diagnóstico de erros do Android Studio e do emulador, ajustes de configuração e scripts de execução e migração de dados.
- **Testes e documentação:** criação e execução de testes, análise dos resultados e elaboração das instruções do projeto, incluindo este arquivo.

## Participação dos desenvolvedores

As telas e o código existente serviram de base para as alterações. O responsável pelo projeto definiu as funcionalidades desejadas e orientou os ajustes por meio de solicitações e observações durante o desenvolvimento. A revisão e a entrega do sistema continuam sob responsabilidade dos desenvolvedores.

## Verificação e funcionamento

Foram realizadas compilações, testes da API e verificações no emulador. Os resultados e as limitações estão registrados em [VERIFICACAO.md](../VERIFICACAO.md).

A IA foi utilizada durante o desenvolvimento. O app e o painel funcionam por meio do código Java, da API PHP e do banco MySQL, sem depender de um serviço de inteligência artificial durante o uso.
